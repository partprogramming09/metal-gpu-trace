# Proof for 0.30.0

**Reader:** people who want to see that each improvement of 0.30.0 was run, with the command and its real output.

Each improvement below was run on the code of this release, on 2026-11-23 (see [docs/evidence/README.md](README.md) for how a proof is read). The recordings are real: fifteen recordings made on this Mac between 2026-11-15 and 2026-11-18 (native Metal and Rosetta runs of the same test program), read through `METAL_TRACE_OUT`. The "before" outputs come from the code of the `v0.29.0` tag. Paths and machine names are left out of every output.

**Where and when (macOS):** macOS 27.2.1, Apple M1 Pro, Xcode 27.2, Python 3.15.0; 2026-11-23.

## The command line answers help instead of hanging

**Promise:** `metal-gpu-trace --help` (or `-h`, or `COMMAND --help`) prints the commands and exits 0; an unknown command prints the usage and exits 2. With no command the server still serves MCP on stdin and stdout.

**Command:** each line is run with stdin closed; the "before" lines hold stdin open for 8 s and kill the process after 5 s.

**Output:**


The official MCP SDK, used as a client by `tests/conformance/`, still starts the server with no argument and gets its `initialize` answer.

**Not tested:** Windows (the command line is the same Python code, but it was not run on the Windows PC for this release).

## doctor says what a recording needs

**Promise:** `metal-gpu-trace doctor` prints one line per check, `ok` or what is missing with the exact fix, without a path, and exits 2 when a recording could not start; it takes no other argument.

**Command:** `metal-gpu-trace doctor`, run on a Mac whose screen was locked at that moment.

**Output:**

```
0.29.0 doctor (stdin open 8 s, killed after 5 s): exit=124

0.30.0
ok       xctrace
ok       disk (temporary folder)
ok       disk (runs folder)
missing  screen: the screen is locked: a locked session leaves the program's frames unpaced by the display, so the numbers do not compare; unlock the Mac, or set METAL_TRACE_ALLOW_LOCKED=1 to record anyway
ok       lock
missing: fix the items above before recording
exit=2
$ metal-gpu-trace doctor --bogus
usage: metal-gpu-trace doctor
exit=2
```

It took 0.22 s of wall time.

**Not tested:** the report on Windows (PresentMon, permissions) and on a Mac without full Xcode.
