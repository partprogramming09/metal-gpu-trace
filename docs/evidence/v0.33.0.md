# Proof for 0.33.0

**Reader:** people who want to see that each improvement of 0.33.0 was run, with the command and its real output.

Each improvement below was run on the code of this release, on 2026-11-26 (see [docs/evidence/README.md](README.md) for how a proof is read). The inputs are real: three screenshots of this Mac's screen (2560 x 1440, taken with `screencapture` one second apart) and a Wine debug log (7899 lines) of CrossOver's Wine on a fresh bottle running `cmd /c ver` with `+timestamp,+pid`. Paths and machine names are left out of every output.

**Where and when (macOS):** macOS 27.2.1, Apple M1 Pro, Python 3.15.0; 2026-11-26.

## screenshots_check flags screenshots that show nothing useful

**Promise:** `screenshots_check` reads PNG screenshots and lists `black`, `uniform`, and, for the frames of one run in name order (`sequence`), `frozen` and `flicker`.

**Command:** the three real captures with `sequence: true`; then the first capture copied three times (the same frame three times) with `sequence: true`.

**Output:**

```
three different captures:  {"frames": 3, "ok": true, "findings": []}
one capture, three times:  {"frames": 3, "ok": false, "findings": [{"file": "f1.png", "problem": "frozen"}]}
```

**Not proven again:** `black`, `uniform` and `flicker` on real screenshots (covered by `tests/test_screenshots.py` with generated PNGs), and the refusal of oversized or lying PNGs.

## wine_log_census counts what a Wine debug log says is missing or wrong

**Promise:** `wine_log_census` counts `fixme`, `err` and `warn` lines by level, channel and message (quoted text, paths, addresses and numbers removed so repeats group), and gives the longest silence between lines that carry `+timestamp`, with the messages on each side.

**Command:** the real 7899-line log, `top` = 5. The silence is checked against an independent script that reads the same file and takes the largest difference between consecutive timestamps.

**Output:**

```
{"lines": 22, "by_level": {"err": 2, "warn": 19, "fixme": 1},
 "by_channel": {"threadname": 18, "winediag": 1, "module": 1, "ntoskrnl": 1, "service": 1},
 "top": [{"level": "warn", "channel": "threadname", "message": "NtSetInformationThread Thread renamed to \"S\"", "count": 18}, ...],
 "largest_gap": {"seconds": 5.016, "before": "module:LdrGetDllHandleEx \"S\" -> NFFFFFF40000 (load path (null))",
                 "after": "winediag:getaddrinfo flags N, load_path N, ..."}}

independent computation over the same file: largest gap 5.016 s, ending at line 395 (the first err line)
```

The `err` and `fixme` lines the census counted are the three a plain `rg` finds in the file (lines 395, 4094 and 4108); no raw line, path or number comes back in the answer.
