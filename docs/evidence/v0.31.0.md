# Proof for 0.31.0

**Reader:** people who want to see that each improvement of 0.31.0 was run, with the command and its real output.

Each improvement below was run on the code of this release, on 2026-11-26 (see [docs/evidence/README.md](README.md) for how a proof is read). The recording is real: one native Metal recording of 1385 frames made on this Mac on 2026-11-19, read through `METAL_TRACE_OUT`. The VegaFlow result is a real `bench.ps1` result file of a Windows run, the one kept in `tests/data/`. Paths and machine names are left out of every output.

**Where and when (macOS):** macOS 27.2.1, Apple M1 Pro, Python 3.15.0; 2026-11-26.

## gate judges a run against a versioned file of limits

**Promise:** `metal-gpu-trace gate RUN` reads `metal-gpu-trace.budgets.json` of the project, prints one JSON line and exits 0 (within the limits), 1 (a number is over its max or under its min) or 2 (it could not judge, for instance a metric that does not exist).

**Command:** the same recording, three budgets files (`{"version": 1, "budgets": {...}}`).

**Output:**

```
budgets: {"gpu_ms_p95": {"max": 12.5}}
{"run": "RUN", "verdict": "pass", "results": [{"metric": "gpu_ms_p95", "value": 6.178, "max": 12.5, "status": "ok"}]}
exit=0
budgets: {"gpu_ms_p95": {"max": 5}}
{"run": "RUN", "verdict": "fail", "results": [{"metric": "gpu_ms_p95", "value": 6.178, "max": 5, "status": "over"}]}
exit=1
budgets: {"fps": {"min": 55}}

```

## import-bench reads VegaFlow bench results as recordings

**Promise:** `metal-gpu-trace import-bench FILE...` turns a `bench.ps1` result into a recording that `runs` lists; importing the same file again changes nothing.

**Command:** the result file of a real 120 s Windows run (3078 frames), imported twice, then `runs`.

**Output:**

```
$ metal-gpu-trace import-bench bench1.json
{"status": "imported", "run": "bench1"}
$ metal-gpu-trace import-bench bench1.json
{"status": "same", "run": "bench1"}
$ metal-gpu-trace runs --limit 3
run                                       frames     fps  gpu ms  metal MiB  rss MiB  layer
upkeep-test-b_20261119-215419                312   103.7   5.904          -  235.156  native
upkeep-test-a_20261119-215316               1385   104.7   5.992          -  183.891  native
bench1                                      3078       -       -          -        -  -
```

**Not proven again:** comparing the jitter of two imported results with `compare` (only one real result file is left on this machine; the comparison is covered by `tests/test_bench_import.py`). That is why the improvement is not marked as a full proof of the comparison.
